# ITZFIZZ — Scroll-driven hero

A responsive React + Vite experience inspired by the supplied “Itz Fizz – Scroll-Driven Hero” reference. The hero uses a pinned GSAP ScrollTrigger timeline to animate the orange car, green reveal, headline, road markings, and metric cards as the visitor scrolls.

## Design details
- Premium editorial layout with a soft mineral-grey canvas, near-black road, acid-green reveal, and orange vehicle.
- Four impact cards based on the reference: 58%, 27%, 23%, and 40%.
- Responsive desktop/tablet/mobile layouts.
- Reduced-motion preference styling.
- Outro section with a return-to-top interaction.

## Run locally
Install Node.js LTS from https://nodejs.org/en/download, then run:

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Deploy to GitHub Pages (GitHub Actions)

This repository includes `.github/workflows/deploy.yml`, which builds the site and deploys it to GitHub Pages whenever you push to `main`.

1. Create a **public** GitHub repository named `itzfizz-scroll-hero`.
2. Upload the project files to the repository root (do not upload the ZIP itself).
3. Open the repository on GitHub and select **Settings → Pages**.
4. Under **Build and deployment → Source**, select **GitHub Actions**.
5. Open the **Actions** tab and wait for the workflow named `Deploy ITZFIZZ hero to GitHub Pages` to finish successfully.
6. Open **Settings → Pages** to find the published website URL. It will usually be:
   `https://SathvikaGNaik.github.io/itzfizz-scroll-hero/`

The workflow deploys the `dist` folder generated by `npm run build`. You do not need to commit `dist` to your repository.

## Deploy after making changes

Edit the source files, then commit and push your changes to the `main` branch. GitHub Actions will build and deploy the new version automatically.

## Animation implementation

`src/App.jsx` contains a GSAP timeline linked to ScrollTrigger. The car and green trail are animated with transforms; headline letters and metric cards are revealed against the same scroll progress. `scrub: 0.65` adds interpolation while keeping the motion scroll-driven.
